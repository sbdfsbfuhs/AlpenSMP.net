Zugang

Der Server ist gratis. Es gibt keinen Vertrag über einen Kauf, kein Abo und keinen Anspruch auf einen Platz, eine bestimmte Spielzeit oder dass eine Welt für immer stehen bleibt.

Im Spiel gelten die Regeln. Wer sie bricht, kann verwarnt, gekickt oder gebannt werden.

Beiträge

Eine Rezension oder ein Bild erscheint erst, wenn das Team sie freigibt. Bis dahin ist sie nicht öffentlich. Das Team darf ablehnen, kürzen oder später wieder wegnehmen, zum Beispiel bei Beleidigung oder wenn das Bild nicht von dir ist.

Du bestätigst beim Senden, dass der Text von dir ist und du das Bild zeigen darfst. Keine erfundenen Bewertungen, keine fremden Fotos, keine Werbung.

Was die Seite nicht verspricht

Keine Garantie auf ununterbrochene Erreichbarkeit, eine bestimmte Spielerzahl oder dass jeder Build stehen bleibt. Aussagen auf der Seite beschreiben den Server, sie sind kein Versprechen eines Unternehmens.

Links zu Discord, TikTok und Modrinth führen auf andere Anbieter. Dafür gilt deren Recht, nicht dieses.
